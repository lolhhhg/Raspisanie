# Расписание

Android-приложение на Kotlin и Jetpack Compose: расписание ПН–СБ, числитель/знаменатель, домашние задания, импорт PDF, офлайн-база Room и фотографии из VK-топика.

## APK

Откройте Actions → Build APK → последний успешный запуск → Artifacts → Raspisanie-APK.

Для VK-фото добавьте секрет репозитория `VK_TOKEN`. Всё остальное работает без токена.
